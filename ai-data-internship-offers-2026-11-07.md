## Application plan

1. Check each portal for an active posting and deadline; save the exact requisition URL.
2. Apply within 48 hours of finding a suitable opening.
3. Tailor the first three CV bullets to the posting's stack (for example: SQL + dbt, PyTorch, Spark, or cloud).
4. Attach the portfolio project described in [`ai-data-portfolio-project-2026-11-07.md`](ai-data-portfolio-project-2026-11-07.md).
5. Track status, referral contact, date applied, and follow-up date in a spreadsheet.
